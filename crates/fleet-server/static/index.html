A deployment is a name, the channel it aims at, one package per agent type, and any number of configurations — the one thing rolled out. An agent belongs to at most one: two matching the same agent is a conflict, and that agent is offered nothing new until a selector is narrowed. There is no fleet-wide default — a selector is equality and cannot say "not", so channels are a partition over an attribute every agent carries (channel = stable), set at provisioning or as a label on the Agents tab.
