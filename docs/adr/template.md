- **Status:** 🟡 proposed
- **Date:** YYYY-MM-DD
- **Deciders:** the names of the humans who decide

_An ADR records what the code cannot say: an external constraint, an alternative
that was rejected, a choice that looks like a mistake, or the condition under
which the choice must be revisited. It does not describe how the code works.
Keep it to 10–20 lines. `Status` ships as `🟡 proposed`; a human flips it to
`🟢 accepted`, `🔴 rejected`, or `⚪ superseded by ADR-NNNN`. Delete this
paragraph._
